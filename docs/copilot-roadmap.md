## 下一轮：独立 Si Memory 与运行可靠性

Agent 是主产品，Memory 是可单独使用的服务。适配器调用同一 Memory Service，
不依赖聊天 Loop，也不另建记忆库。设计依据见[上下文与服务边界](copilot-context-budget-design.md)。

1. **MCP 读取闭环**：可选 stdio 服务，启动时绑定身份、项目及权限；提供 search/read/list，返回相同的 URI、证据、版本与层级表示。
2. **MCP 写入闭环**：propose/candidate_status 使用幂等请求；外部模型不能直接批准自己的候选或危险遗忘。服务端继续执行证据、冲突、版本及 tombstone 检查。
3. **外部 Agent 演示**：提供配置及可运行客户端示例，验证外部查询与 Si-agent 跨会话共享记忆；覆盖跨项目拒绝、重复提交、修正与忘记后不可召回。客户端示例不能代替实际协议验收。
4. **运行可靠性回归**：覆盖长会话、多轮工具、收缩、审批恢复和模型长度拒绝；确认上下文处理不破坏工具对应关系、预算、事件流或遗忘语义。

验收交付为 MCP 服务、配置示例、确定性测试和中文接入报告。远程 HTTP MCP 需要鉴权、作用域令牌与部署边界，首轮不开放无鉴权公网访问。
后续按 7B/7C 推进；Jev 保持禁用，检索门策略在完成标注集对照后再调整。

### 7A：真实模型与向量基线

已接通 hy3、真实抽取与 Qwen 1024 维 Embedding，完成导入、修正、跨会话引用及 SQLite 检索基线。
已冻结 48 条检索和 16 条留存合成样本；独立人工复核、留存评分和 PostgreSQL 质量基线尚未验收。
因此 7A 当前属于部分验收，边界与失败记录见[7A 报告](copilot-week7a-release.md)。

以“Si-agent 自身的项目决策与开发记录”为固定演示项目，配置一个真实聊天模型、
一个抽取模型和一个 Embedding 模型。先检查模型能力、向量维度、分块、索引覆盖与版本，
再验证中文改写提问、跨会话追问和事实修正。模型与密钥保留在后端；外部请求采用显式配置。

建立至少 60 条人工标注的中文检索与留存样本，涵盖项目事实、语义改写、时序更新、
相互冲突、无答案、跨项目隔离和忘记后的检索。数据集区分阈值校准集与最终测试集。
查询标注正确来源 URI、证据和有效时间，留存样本标注应保存或应拒绝的依据。
先冻结语料、模型、索引和查询，再开展后续比较。

验收交付包含配置说明、可重复导入数据、真实模型端到端记录与基线结果。
当前哈希演示向量不能作为语义检索能力的基准。

### 7B：评测运行器与 Eval Lab

使用统一数据格式比较旧 SQLite FTS5 基线、自研 PostgreSQL 关键词检索与 hybrid 检索。
各后端使用相同语料、问题、top-k、预算和有效时间；涉及抽取差异时单独报告。
将纯检索能力、记忆生命周期和 Agent 完成任务的结果分别记录，避免把入库差异混入召回分数。

运行器输出 Recall@k、MRR/nDCG、证据引用正确率、项目泄漏率、过期命中率、
稳定事实留存率和污染率，并区分模型用量、实际计价依据、端到端延迟及检索延迟。
本轮遵照用户要求暂不接入 Jev，检索门与候选留存继续采用本地规则。
以后启用 Jev 时，应与本地规则在同一数据集上对照；阈值由校准集确定，最终测试集用于报告，
不根据演示个例直接替换默认策略。Agent 评测覆盖工具参数、审批、幂等、partial/unknown 和预算。

新增后台评测任务、结果查询接口和中文 Eval Lab 页面，展示数据集版本、后端、配置、
指标、失败样本与证据。外部服务未配置时展示不可用原因，不填充模拟成绩。
确定性测试负责边界，LLM judge 仅辅助语言质量和 groundedness 判断。

验收要求同一固定配置能够重复执行并导出 JSON/中文 Markdown 报告。
隔离与忘记用例要求无违规命中；召回质量先公开实测基线，再确定优化目标。

## Langfuse 验收要求

Langfuse 是第五周优先观测后端。Si-agent 拥有事件协议、运行记录和评测标准，
Langfuse 通过可选适配器提供存储与查询；未启用时产品仍可运行。

- 每次运行有根 trace，关联用户、项目、会话、run 和模型。
- span 包围真实操作，记录异常、重试、取消和超时。
- 检索阶段包含 scope/gate、query embedding、两路召回、融合、表示层级与预算。
- 导入和索引关联 job、node、revision 和 evidence ID。
- 摘要、consolidation、judge 等 Loop 外调用也统计 usage 与成本。
- 工具记录结构化状态与 operation ID，区分估算和实际收费。
- 持久化与导出前脱敏，原文和 prompt 收集可配置，密钥不进入事件。
- 导出异步且有界，关闭时 flush，失败不能破坏业务运行。
- 验证固定版本的 SDK/OTel 协议、鉴权与属性映射。
- 分数记录对应运行、证据、evaluator、版本、judge 模型与数据集。

第五周确定性测试覆盖内存 sink 和本地 OTLP HTTP/protobuf 接收端。
真实 Langfuse 自托管部署、细分 lexical/vector/RRF 观测、原文采集开关和 score 导出需要后续验收。
当前可将已有 Langfuse 实例地址注入 Worker；主 Compose 不包含 Langfuse 服务。
验收检查父子关联、持续时间、并发、脱敏、导出降级和辅助调用 token 总数。
在线质量检查与运行时硬预算分别测试。
