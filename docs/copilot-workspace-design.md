# 对话工作台与项目文件夹设计

本轮让项目与会话成为主导航，资料和记忆通过侧栏按需查看，技术监控通过独立 `/monitor` 页面访问。
主会话展示可审计的运行步骤、工具状态、审批和模型逐段输出，不展示模型私有思维链。
SSE 延续持久化游标与重放，模型流中断后保留未完成状态，不把部分文本写成最终答案。
输出事件按小批量持久化，重试前重置当前生成；取消、来源撤回和租约检查继续生效。

项目可以关联显式配置根目录下的本地文件夹，也可以导入浏览器选择的文件夹快照。
两种模式在界面上明确区分：本地模式可读取实时文件，快照模式不具备持续磁盘访问。
目录枚举与工具只访问用户关联的文件夹，拒绝符号链接、越界路径、密钥文件和生成目录。
第一阶段文件工具只支持列表、文本读取和搜索，不具备命令执行或磁盘写入权限。
导入保留相对路径，预览文件清单、过滤结果和大小，分批提交到现有持久化任务链路。
模型产生的记忆建议保留审核边界，用户默认只看待确认的自然语言变更与来源，不被历史候选和后台任务淹没。

数据库主路径切换至实际 PostgreSQL/pgvector，原 SQLite 保留备份并以显式导入脚本迁移到空目标库。
迁移保留主键、会话、版本、证据和向量，目标非空时拒绝覆盖。前端显示当前数据库类型。
观测面板独立展示运行列表、模型用量、真实 span 时间、错误和后台任务，不充当记忆审核入口。
Langfuse 的服务验收继续保留为后续工作，当前自有监控不能冒称已完成 Langfuse 实例联调。
