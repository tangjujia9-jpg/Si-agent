# Si-agent 工作台使用说明

Si-agent 以项目和会话组织工作。左侧导航切换项目及其会话，中间展示对话，右侧按需查看资料、记忆与来源。项目监控在独立页面打开。

## 项目与文件夹

点击左侧“添加项目”或项目标题旁的加号，选择以下一种方式：

| 方式 | 使用方法 | 文件访问范围 |
|---|---|---|
| 本地文件夹 | 在已配置工作目录中浏览并选择项目根目录 | 文件工具实时读取此目录，资料导入时才建立长期索引 |
| 导入文件夹 | 通过浏览器选择文件夹，确认名称并创建项目 | 浏览器上传文本快照，无法持续读取原磁盘 |

服务器通过 `SI_WORKSPACE_ROOTS` 明确允许浏览的根目录，Windows 使用分号分隔。未配置时可以使用浏览器快照模式。
目录和文件读取拒绝越界、符号链接、隐藏/敏感文件以及生成目录。文件工具只读，不提供 shell 或磁盘写入。
现有的旧项目显示“资料快照”，原有会话和资料继续可用。

“项目资料”打开右侧资料栏。用户可以上传文件、上传文件夹，或扫描关联的本地项目。
页面先展示文件清单，用户勾选后才提交导入。导入保留相对路径，支持 UTF-8 Markdown、文本和代码；PDF、Word、图片和网页解析尚未接入。
清单最多包含 500 个文件，单文件不超过 200 KB；每个批次不超过 50 份资料或约 1.9 MB。
隐藏、敏感、重复、不支持或超限的文件会计入过滤数量。
导入会分批进入持久化任务，网络失败重试沿用批次幂等键。原文保存后，摘要、向量和候选记忆继续在后台处理。
“刷新资料”重新读取保存结果；“浏览上下文目录”可以展开目录、会话来源和记忆。

## 对话与执行过程

“新对话”建立当前项目下的会话，左侧会话列表支持切换。浏览器记住每个项目最近访问的会话。
中间正文支持 Markdown、代码、列表、表格和来源引用。长历史可向前加载。

发送消息后，对话中展示检索、模型调用、工具执行和审批状态。支持流式的 Provider 会通过持久化 SSE 逐段输出文字；没有流式能力的模型在完成后展示全文。
执行完成后，过程默认折叠。用户可以展开最近运行的关键步骤，或进入项目监控检查历史记录。
过程展示的是实际操作事件，不是模型的私有思维链。

模型选择器优先使用已配置的真实模型，并记住用户选择。`evidence-demo · 离线演示` 只展示检索证据。
密钥保存在后端，浏览器只请求 Si-agent API。
Enter 发送，Shift + Enter 换行；中文输入法组词时不会误发送。
“停止生成”请求取消运行；它不能撤销已经执行的动作。

本地/快照文件工具可以浏览文件、分段读取和搜索文本。读取结果带行号和续读位置，并受输出预算约束。
事实回答中的有效 `si://` 引用打开已持久化的来源；实时文件路径引用属于磁盘资料，不冒充已有长期记忆证据。

“记忆建议”控制模型可用的记忆修改工具。写操作仍需在对话内批准或拒绝。
此开关不停止会话后台整理；后台建议仍需用户确认，不能直接成为正式事实。

连接中断时，客户端从持久化游标重连，重复事件不会重复拼接回答。
模型流中断后，已显示文字保留为未完成输出，系统不会将它写成成功回答，也不会在发布部分文字后自动重复请求模型。
页面刷新会加载消息和运行事件。忘记来源后，相关输出事件也会脱敏。

## 项目记忆与来源

“项目记忆”默认展示“已记住”的事实、决策和规范，可通过关键词筛选。
“待确认建议”只显示当前需要处理的建议和保存冲突，使用自然语言展示建议内容、来源和保存操作。
点击“保存这条记忆”后，后台完成版本/证据校验与合并，正式记忆才会更新。
点击“忽略”保留来源，但不将此建议写入正式记忆。发生版本或来源冲突时，页面会说明尚未保存，并提供核对当前记忆与忽略建议的入口。
历史建议通过历史按钮按页查看，每页 30 条；后台任务集中在监控页面。

点击资料、记忆或回答引用打开“来源详情”，可以切换“摘要 / 概览 / 原文”，查看来源引用、历史版本并打开原始依据。
URI、版本和证据位置保留在可展开的详情中。
“修正这条记忆 → 保存修改”将当前用户陈述作为新证据，直接排队执行已由用户确认的变更，无需再次进入建议页批准。
“撤回事实”使记忆退出检索并保留历史；“忘记此来源”脱敏正文、历史和已知依赖，并保留遗忘屏障。
忘记前必须预览影响并确认。系统不能撤销已经发送给外部模型的内容。

右上角检索按钮提供独立证据查询，可查看召回片段，展开技术详情检查上下文预算和检索阶段。
这个入口不调用聊天模型，也不经过聊天检索门。

## 独立项目监控

左下角“项目监控”在新标签打开 `/monitor?project=...`。
页面展示当前项目最近 100 次运行与最近 100 个后台任务，支持项目切换、记录筛选和手动刷新。
概览显示成功数量、模型报告 token 和失败任务；这些数字不是全历史统计或实际账单。

运行详情展示状态、模型、迭代、操作审批和真实调用时间线。
时间线使用 span 的开始/结束时间、父子关系和高精度持续时间，覆盖检索门、查询 Embedding、关键词查询、向量查询、融合、上下文组装、模型与工具。
每个层级复用同一查询向量，L0/L1/L2 召回耗时不包含另一轮 Embedding。
小于 1 ms 的测量显示 `< 1 ms`，缺失值显示“未记录”。旧事件保留当时的计时精度。
后台任务详情提供尝试次数、错误和处理结果。

此页面读取 Si-agent 自身的持久化记录。Langfuse OTLP 适配器已经存在，真实 Langfuse 实例部署、trace 跳转与服务验收仍属于后续工作。
Eval Lab、Provider 配置编辑器和公网身份认证尚未提供。

## 本机入口

当前本机工作台使用 `http://127.0.0.1:5186`，API 使用 8016。
左下角可以确认实际数据库类型，`/api/system` 返回数据库及 pgvector 版本，不返回连接凭据。
启动步骤见[后端手册](copilot-backend.md)，本轮验收见[工作台报告](copilot-workspace-release.md)。
